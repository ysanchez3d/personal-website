# personal-website

Source for [yandrisanchez.com](https://yandrisanchez.com) — built with Astro and TypeScript.

## Commands

| Command | What it does |
|---|---|
| `npm install` | Install dependencies |
| `npm run dev` | Start the dev server at `localhost:4321` |
| `npm run build` | Build the site into `dist/` |
| `npm run preview` | Preview the built site |
| `npm run typecheck` | Type-check `.ts` and `.astro` files |
| `npm test` | Run tests (builds the site and checks the output) |
